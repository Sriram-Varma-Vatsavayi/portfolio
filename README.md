# Portfolio Website - Sriram Varma Vatsavayi

A modern, professional portfolio website showcasing skills, experience, and projects in Information Technology and Machine Learning.

## 🚀 Features

- **Modern Design**: Clean, professional interface with smooth animations
- **Responsive Layout**: Mobile-first design that works on all devices
- **Dark/Light Mode**: Automatic system preference detection with manual toggle
- **Interactive Elements**: Hover effects, smooth scrolling, and engaging animations
- **Contact Form**: Functional contact form with validation
- **SEO Optimized**: Proper meta tags and semantic HTML structure

## 🛠️ Technology Stack

- **Framework**: React 19.1.1
- **Build Tool**: Vite 7.1.2
- **Styling**: Tailwind CSS 3.4.17
- **PostCSS**: ES Module configuration
- **Fonts**: Inter & Poppins from Google Fonts
- **Icons**: Custom SVG icons
- **Deployment**: Ready for static hosting (Vercel, Netlify, GitHub Pages)

## 📦 Installation & Setup

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Open in browser**
   Navigate to `http://localhost:5173`

## 🏗️ Build & Deployment

```bash
# Build for production
npm run build

# Preview production build locally
npm run preview

# Run linting
npm run lint
```

## 🎨 Customization

### Update Content
Edit `src/data/portfolioData.js` to update:
- Personal information
- Education details
- Work experience
- Skills and technologies
- Project information
- Contact details

### Modify Styling
- Colors: Update `tailwind.config.js`
- Typography: Modify font imports in `src/index.css`
- Layout: Adjust component styles in individual component files

### Add New Sections
1. Create new component in `src/components/`
2. Import and add to `src/App.jsx`
3. Update navigation in `src/components/Navigation.jsx`
